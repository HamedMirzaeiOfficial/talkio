# Contributing

## Local development

Work from `src/`, create a virtual environment, install `requirements.txt`, copy `.env.example` to `.env`, run migrations, and start Django. Redis/PostgreSQL are required for the production-shaped Compose profile; SQLite and the in-memory channel layer are suitable only for isolated local development.

## Before opening a pull request

- Run `python manage.py check` and `python manage.py test`.
- Add a regression test for behavior changes, especially authorization and reconnect paths.
- Keep migrations backward-compatible and do not reset the local database.
- Do not commit secrets, local databases, media, static build output, or generated bytecode.
- Update the protocol/security documentation when transport or authorization behavior changes.

## Commit guidance

Prefer small, focused commits with a clear reason. Avoid mixing visual redesigns with persistence or authorization changes unless the change is inseparable.
